#  My Personal CDN Static Assets

> 本仓库用于存储个人博客、项目所需的静态资源（图片、CSS、JS等），并通过 jsDelivr 实现全球 CDN 加速访问。

##  仓库说明

- **用途**：图床 / 前端静态资源托管
- **加速服务**：[jsDelivr](https://www.jsdelivr.com/)
- **访问协议**：HTTPS

---
